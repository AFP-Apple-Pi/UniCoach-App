# Fictional mentor evaluation evidence

These records contain only the invented coursework and predeclared evaluation questions in `AppTests/Fixtures/mentor-evaluations.json`, plus the fictional long-context stress material. They contain no prior user records or private uploads.

Each version/case JSON preserves the first saved output and actual model processing steps. Technical receipts show completion of the UI workflow, not semantic correctness. Saved text can include deterministic clarification or session formatting; `processingSteps` retains the actual model prompts, schemas and outputs. A same-model supported verdict is not independent proof of truth. See [the assessment and limitations](../../MENTOR_QUALITY.md).

V1 through V5 include failed interpretations and false abstentions that motivated general schema and validation changes. V6 is the final eligible-reference isolation check. No failed first result was replaced by a favorable retry. Mechanical proof files verify only the stated text, timing and provenance properties.
